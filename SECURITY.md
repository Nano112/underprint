# Security policy

Please report security issues privately to `contact@schem.at`. Do not open a
public issue for vulnerabilities involving unsafe media parsing, native memory,
model integrity, evidence verification, or authentication bypass.

Include the affected version/profile, platform, reproduction steps, and impact
when possible. Uploaded media used to reproduce a report must be content you
are authorized to share.

Underprint is pre-1.0. Only the latest development release receives security
fixes until a supported-release policy is published.
